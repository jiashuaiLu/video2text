# 多端与商业化可行性分析

写于 2026-11。结论先行，依据在后。

## 一句话结论

**桌面端可以卖（买断制），移动端建议只做"本地音视频转文字"、坚决不碰链接抓取**。
原因是三件事同时成立：应用商店政策、平台条款、手机算力。

---

## 一、技术可行性

| 平台 | 转写后端 | 能否本地跑 | 主要障碍 |
|---|---|---|---|
| macOS (现状) | MLX + Qwen3-ASR 1.7B | ✅ 24s / 7.7min 音频 | 仅 Apple Silicon |
| Windows | whisper.cpp (GGML) 或 ONNX | ✅ CPU 跑 large-v3-turbo 约 3-8x 实时 | 需换后端，GPU 加速碎片化 |
| iOS | Apple SpeechAnalyzer / whisper.cpp(Metal) | ✅ 但模型 1-2GB | 包体、首次下载、发热 |
| Android | whisper.cpp / ONNX Runtime | ⚠️ 中端机慢 1-3x 实时 | 机型碎片、耗电 |

**关键点**：ASR 模型是可以商用的开源许可——Qwen3-ASR 与 Qwen3.5 为 Apache-2.0，Whisper 为 MIT，MLX 为 MIT。打包进闭源 App 没问题，只需保留版权声明。

**但移动端的痛点不是"能不能跑"，是"跑得多难受"**：7 分钟视频在 iPhone 上本地转写 1-2 分钟、掉 5-8% 电量、机身明显发热。用户第一次的体验往往决定留存。

## 二、合规风险（决定成败的那 80%）

这条比技术重要得多。

1. **App Store 审核**：苹果对"从第三方平台抓取/下载内容"的 App 长期从严（Guideline 5.2.3）。"粘贴抖音链接自动下载并转写"这种形态，**高概率被拒**，已有大量先例。
2. **平台条款**：抖音、B 站的用户协议都禁止未授权的抓取与二次分发。桌面端做开源工具，风险主要在用户侧；一旦做成面向大众的商业 App 并收费，责任会前移到你身上。
3. **国内安卓渠道**：华为、小米、应用宝上架需版权或资质材料，"视频下载"类目基本走不通。

**规避路径**（按推荐度排序）：

| 方案 | 说明 | 审核风险 |
|---|---|---|
| A. 只处理本地文件 | 用户自己录屏/保存后导入 | 低 ✅ |
| B. 桌面端做浏览器扩展 | 扩展在用户已登录的页面里运行，绕过应用商店 | 中 |
| C. 服务端代为下载 | 你承担 IP 池与合规责任 | 高 ❌ |

**明确不建议**：把"抖音链接直连"作为移动 App 的主打功能。

## 三、商业模型对比

移动端现状你观察得对：几乎全是**会员制 + 次数限制**（讯飞听见、通义听悟、各类"录音转文字"）。原因很实在——**云端 ASR 是按分钟付费的**，阿里/讯飞的商用 ASR 约 1.2-2 元/小时，8 分钟视频成本约 0.2 元。不做订阅和限额，用户重度使用就会亏。

而**本地推理的边际成本是 0**，这给了买断制的空间。桌面端的成功先例：MacWhisper（一次性 €29-59）、Vibe（开源免费+捐赠）。

### 建议的产品矩阵

| 产品 | 卖点 | 定价 |
|---|---|---|
| 桌面 · 免费版 | 本地无限次转写、规则排版 | ¥0 |
| 桌面 · Pro（买断） | 批量队列、AI 整理、字幕翻译、导出模板 | **¥68-98 一次性** |
| 移动 · 基础 | 本地文件/录音转文字，无限次但慢 | **¥30 买断** |
| 移动 · 云加速包 | 云端转写额度（把慢变成快） | ¥12 / 10 小时 |

逻辑是：**用"本地无限次"打竞品的"次数限制"，用"云额度包"覆盖愿意为速度付费的人**。这样既保留了买断的干净感，又不会在重度用户身上亏钱。

## 四、成本与盈亏

单用户成本结构（桌面 Pro，全本地）：

```
一次 8 分钟视频：ASR 本地 = ¥0；AI 整理走 DeepSeek ≈ ¥0.005
```

也就是说桌面版**毛利接近 100%**，只有获客成本。移动端若默认走云，则每 8 分钟约 ¥0.2，必须靠额度包或订阅覆盖。

## 五、竞争格局

- **免费且强**：剪映（自带识别字幕）、飞书妙记、通义听悟免费额度
- **开源**：Vibe、Buzz、whisper.cpp 生态、Douyin_TikTok_Download_API（21k star，已含离线转写）
- **收费**：MacWhisper、讯飞听见

**空位在哪**：这些工具要么是"字幕/时间轴"，要么要上传服务器。**没人把"链接→成稿"做成一个开箱即用、默认离线、还自带中文排版与术语纠错的产品**。这正是 v2t 的差异点，也是它值得开源的原因——先占领"能出稿"这个心智。

## 六、推荐路线

1. **现在**：开源桌面版（MIT），把"中文成稿质量"做成口碑。开源是获客成本最低的路径。
2. **3-6 个月**：推出 Pro 买断版（许可证 key 校验 + 批量 + 翻译），开源版保持核心可用。
3. **移动端**：只做 A 方案（本地文件/录音），主打"离线、隐私、无限次"，云加速作为可选额度包。
4. **不做**：链接直连的移动 App。

## 七、风险清单

- 抖音/B 站反爬升级会持续破坏抓取链路（桌面端已有 CDP 兜底，但仍需维护）
- 开源后竞品可快速复制，护城河只有"成稿质量 + 品牌"
- 模型许可证需随包附带声明（Apache-2.0 / MIT）
- 若走订阅，需处理退款、发票、支付渠道（国内需企业主体）
